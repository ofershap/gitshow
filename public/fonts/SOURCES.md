# Bundled fonts

The WOFF2 files are the exact Google Fonts subsets emitted by the last successful Next.js build. Keeping them here removes the build-time network dependency. Font families, requested weights, unicode ranges, fallback metrics and Latin preloads are unchanged.

- dmsans: https://github.com/google/fonts/blob/main/ofl/dmsans/OFL.txt
- outfit: https://github.com/google/fonts/blob/main/ofl/outfit/OFL.txt
- jetbrainsmono: https://github.com/google/fonts/blob/main/ofl/jetbrainsmono/OFL.txt
